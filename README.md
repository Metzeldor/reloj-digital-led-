# 🕒 Reloj Digital LED en CSS

Reloj digital interactivo con estética de pantalla LED de 7 segmentos, efectos de brillo neón y chasis oscuro. Construido con HTML5, CSS3 y JavaScript Vanilla.

## ✨ Características
- **Display LED dinámico:** Tipografía de 7 segmentos con efecto de resplandor (`text-shadow`).
- **Selector de color LED:** Alterna entre 4 colores clásicos (Cian, Verde matriz, Rojo y Ámbar).
- **Formato dual:** Cambia en tiempo real entre formato de **24 horas** y **12 horas (AM/PM)**.
- **Indicador de fecha y día:** Resalta automáticamente el día de la semana activo.
- **Diseño responsivo:** Se adapta a pantallas de escritorio y dispositivos móviles.

## 🚀 Cómo probarlo
1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` directamente en tu navegador web favorito.
