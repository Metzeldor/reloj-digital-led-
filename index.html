6 conceptos en el reloj

Cada tarjeta muestra una técnica real del proyecto, con su demo y el código que la hace posible.

1 · Variables CSS (temas)

Un solo cambio de --led recolorea toda la página.

:root { --led: #00f3ff; }
.screen { color: var(--led); }

2 · Brillo neón

12:34

Varias capas de text-shadow con radios crecientes simulan el resplandor.

text-shadow:
  0 0 6px var(--led),
  0 0 14px var(--glow),
  0 0 30px var(--glow);

3 · Chasis con profundidad

Sombra externa más inset crean relieve y pantalla hundida.

box-shadow:
  0 20px 50px rgba(0,0,0,.8),
  inset 0 1px 1px rgba(255,255,255,.08);

4 · Tipografía fluida

Cambia el tamaño de la ventana

clamp() escala el texto sin media queries.

font-size: clamp(3.5rem, 12vw, 6.2rem);

5 · Animaciones

@keyframes para el parpadeo y transition-delay escalonado al pasar el cursor.

.colon { animation: blink 1s steps(1) infinite; }
@keyframes blink { 50% { opacity: .15; } }

6 · Reflejo de cristal

Un pseudo-elemento con gradiente diagonal da el brillo del vidrio.

.screen::after {
  content: ""; position: absolute; inset: 0;
  background: linear-gradient(135deg,
    rgba(255,255,255,.18), transparent 55%);
}
